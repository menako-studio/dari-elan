# Darielan - Photography Portfolio

An introspective, editorial-style photography portfolio for Elan Budikusumah, built with Next.js 16 and Tailwind CSS v4.

## Overview
This project serves as a digital gallery and manifesto, heavily inspired by modern editorial print layouts. It embraces an off-white palette, hairline dividers, asymmetrical grid layouts, and strict typography rules to create a therapeutic and observant visual experience.

## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Analytics:** Vercel Analytics & SpeedInsights

## Features
- **Editorial Layouts:** Asymmetrical column structures and full-bleed image interruptions.
- **Introspective Tone:** Copywriting and visual design centered around raw, unpolished, emotional storytelling.
- **Interactive Collage:** A personal projects page simulating physical photos scattered on a desk, with ambient audio and intimate viewing modes.
- **Strict Design System:** Absolute zero border-radius, strict typography scale, and hairline dividers.
